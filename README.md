# فرنوسا CMS

مرحله اول سیستم مدیریت منوی دیجیتال Fernosa با PHP 8.2+، MySQL و PDO است. این مرحله شامل ساختار دیتابیس، نصب‌کننده، نشست امن، ورود مدیر، تغییر رمز اجباری و داشبورد آماری اولیه است.

## پیش‌نیازها

- PHP 8.2 یا بالاتر با افزونه‌های `pdo_mysql`, `mbstring` و `fileinfo`
- MySQL 8 یا MariaDB 10.5 به بالا
- Apache با `mod_rewrite` فعال

## نصب با XAMPP

1. پوشه پروژه را داخل `C:\xampp\htdocs\fernosa-cms` قرار دهید.
2. Apache و MySQL را از XAMPP Control Panel اجرا کنید.
3. آدرس `http://localhost/fernosa-cms/install.php` را باز کنید.
4. آدرس پروژه، اطلاعات MySQL و رمز مدیر را وارد کنید. کاربر MySQL باید اجازه ساخت دیتابیس داشته باشد؛ در نصب پیش‌فرض XAMPP معمولاً `root` بدون رمز است.
5. پس از نصب، فایل `install.php` را حذف یا خارج از web root نگه دارید.
6. وارد `http://localhost/fernosa-cms/admin/login.php` شوید و در اولین ورود رمز را تغییر دهید.

## نصب با Laragon

پوشه را داخل `C:\laragon\www\fernosa-cms` بگذارید، سرویس‌های Apache و MySQL را روشن کنید و دامنه محلی نمایش‌داده‌شده توسط Laragon را در فیلد «آدرس پروژه» وارد کنید. سپس مراحل نصب بالا را ادامه دهید.

## نصب روی cPanel

1. فایل‌ها را در `public_html` یا یک پوشه دامنه فرعی بارگذاری و از حالت فشرده خارج کنید.
2. در MySQL Databases یک دیتابیس، کاربر و رمز بسازید و کاربر را با دسترسی کامل به دیتابیس متصل کنید.
3. `install.php` را در دامنه باز کنید؛ در cPanel معمولاً نام دیتابیس و کاربر با پیشوند حساب ساخته می‌شوند.
4. آدرس نهایی، مانند `https://fernosa.ir`، را بدون `/` پایانی وارد کنید.
5. پس از نصب `install.php` را حذف کنید و دسترسی `app/config/config.php` را فقط برای کاربر وب‌سرور نگه دارید.

## انتقال به fernosa.ir

بعد از انتقال فایل‌ها و ایمپورت یا نصب دیتابیس، مقدار `APP_URL` در `app/config/config.php` باید `https://fernosa.ir` باشد. گواهی SSL را فعال کنید و در صورت تغییر نام دامنه، لینک‌های ذخیره‌شده در تنظیمات را نیز از پنل به‌روزرسانی کنید.

## ورود اولیه

نام کاربری: `admin`

رمز پیش‌فرض نصب: همان رمزی که در installer وارد می‌کنید؛ مقدار پیشنهادی `Fernosa@2026` است. تغییر رمز در اولین ورود اجباری است.

## نکات امنیتی

- `install.php` بعد از نصب نباید عمومی باقی بماند.
- رمز دیتابیس و فایل config را در Git یا خروجی عمومی قرار ندهید.
- برای محیط production حتماً HTTPS، رمز قوی و پشتیبان منظم دیتابیس فعال باشد.
